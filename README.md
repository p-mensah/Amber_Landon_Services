## Overview

Amber Landon Services is a cutting-edge, highly interactive shipping and logistics website built with modern web technologies. This React-based application showcases a comprehensive logistics company offering end-to-end solutions from product branding and design to global procurement and shipping.

## Features

### 🚀 Core Services
- **Product Branding & Design** - Unique brand identities and product designs
- **Global Procurement** - Strategic sourcing from worldwide suppliers
- **Air & Sea Cargo** - Reliable and efficient freight solutions
- **Supplier Visitations** - On-site quality control and relationship building

### 🎨 Technical Highlights
- **Advanced Animations** - Smooth transitions and micro-interactions throughout
- **Interactive Elements** - Dynamic hover effects and scroll animations
- **Particle Effects** - Beautiful background animations using Three.js
- **Progressive Image Loading** - Optimized image loading with blur placeholders
- **Dark/Light Theme** - Automatic theme switching with smooth transitions
- **Responsive Design** - Fully mobile-responsive layout
- **Real-time Chat Widget** - Interactive customer support system

### 🛠️ Technology Stack

#### Frontend
- **React 19** - Modern React with hooks and functional components
- **TypeScript** - Type-safe development
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework
- **Swiper** - Touch-enabled sliders and carousels
- **Typed.js** - Animated typing text effects

#### Development Tools
- **TypeScript** - Static type checking
- **ESLint & Prettier** - Code quality and formatting
- **Git** - Version control with comprehensive commit history

## Installation

### Prerequisites
- Node.js (version 18 or higher)
- npm or yarn package manager

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/p-mensah/Amber_Landon_Services.git
   cd Amber_Landon_Services
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser and navigate to:**
   ```
   http://localhost:3000
   ```

## Key Components

### 🎭 AnimatedElement
A wrapper component that provides entrance animations for sections:
- Fade-in-up animations
- Zoom-in effects
- Custom delay timing
- Scroll-triggered animations

### 🎨 ParticlesCanvas
Interactive 3D particle background using Three.js:
- Dynamic particle movement
- Mouse interaction effects
- Performance-optimized rendering
- Theme-aware color schemes

### 🖼️ ProgressiveImage
Optimized image loading component:
- Blur-up technique for perceived performance
- Lazy loading for better page speed
- Placeholder images during load
- Smooth transition effects

### 💬 ChatWidget
Interactive customer support widget:
- Real-time chat interface
- Typing indicators
- Message history
- Responsive design

### 🎯 ServiceModal
Detailed service information modals:
- Smooth entrance animations
- Service-specific content
- Close functionality
- Keyboard navigation support
